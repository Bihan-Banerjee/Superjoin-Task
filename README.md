# Fact Knowledge Layer

Ingests PDFs, extracts facts that are grounded in verifiable evidence, and works out where
those facts agree, disagree, or only appear to disagree because they were measured over
different periods, scopes, units or data vintages.

Built for the Superjoin engineering intern assignment. Nothing in the pipeline is specific
to the starter documents: there are no hard-coded facts, filenames, measures or schemas.
